# logos/ — design scratch pad. Nothing here ships.

**Read this if:** you are iterating on logo/wordmark options and want the previous rounds.

**Skip if:** you need a logo the SITE serves — those live in `public/logos/` and are reached at
`/logos/…`. Same folder name, opposite status.

**Below:** `iterations/` · `preview.html`

**Update this file when:** an iteration set is promoted to `public/logos/` or this folder is
retired — same commit.

## What's here

`iterations/` holds three comparison sheets (`set-a.html`, `set-b.html`, `set-c.html`) and
`preview.html` renders them. They are opened directly in a browser from disk — they are not routed,
not built, and not linked from any page.

⚠ **Promotion is a copy, not a move**, and it is manual: a mark is only live once the asset exists
under `public/logos/` and something references it. Editing a file here changes nothing a visitor
can see.

Method for the iteration work itself: meetsoma's `skills/logo-lab`.
